# SmartCare scenario


## 1. Problem summary

SmartCare Community Clinic currently uses spreadsheets and paper files to keep track of patients and appointments. This can be slow, hard to manage, and may lead to mistakes such as lost information, double bookings, or outdated records. Staff may spend extra time searching for information or updating records. The clinic wants a software system that makes it easier to manage patients, practitioners, and appointments in one place. However, the client\'s request is very broad and does not provide enough detail to understand what the system needs to do fully. We will need more information before development can begin.

# AI Activity Card - Ask, Check, Explain

## Before AI

What do I think the code does? What problems can I already identify?

## AI request

Act as a tutor. Explain this code and identify potential problems. Do
not provide a complete replacement. Ask me questions that help me reason
about the solution.

## Evaluate

  --------------------------------------------------------------------------
  Suggestion     Useful         Unclear        Incorrect      Out of scope
  -------------- -------------- -------------- -------------- --------------
                                                              

                                                              

                                                              

                                                              
  --------------------------------------------------------------------------

## Decide

For each significant suggestion: Accept / Modify / Reject / Keep
unverified.

## Verify

- Run the code

- Test normal input

- Test unusual input

- Compare with requirements

- Ask tutor/peer

- Check documentation

## Explain

Can I explain the final code without reading the AI response? What do I
still need to understand?
